# Polymarket → Telegram, v1

Список наблюдения: бот читает публичные рынки Polymarket и печатает исходы с высокой ценой ask. В Telegram сообщение уходит только если заданы токен и chat id.

Кошелька нет, ордера не ставятся. Высокая цена — это уже вероятность рынка, а не найденное преимущество. Покупка по 0.90 ставит 0.90 ради оставшихся 0.10, и один промах съедает длинную серию таких покупок.

## Запуск

Python 3.11+, сторонние пакеты не нужны.

```bash
cp .env.example .env
python3 -m polymarket_alerts
python3 -m polymarket_alerts --loop
python3 -m unittest discover -s tests -v
```

Без `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` программа печатает уведомления в консоль и пишет в stderr строку итога. Повтор того же исхода глушится файлом `.alert-state.json` (12 часов или сдвиг ask на 0.03).

Пороги по умолчанию: ask от 0.90 до 0.97, ликвидность от $10 000, объём 24ч от $5 000, спред не шире 0.03, до `endDate` от 2 часов до 14 дней. Их можно заменить в `.env`.
